# 生成与验收输出

本目录放置便于浏览、比较和验收的派生结果，不是正式数据源。

- `.png` / `.jpg` 常为画面、页面或移动布局截图；`.html` 是可浏览的复核或对照页面。
- `.json`、`.md`、`.srt` 和日志文件保存模型比较、片段复核、报告或运行诊断结果。
- ASR 片段与人工验收截图可能被报告或结论引用；已交付或作为证据引用的文件应保留。
- 普通预览能否重建取决于源材料与当前版本；不要整目录删除来清理缓存。
- 当前阶段从 [scripts/workflow.py](../scripts/workflow.py) 规划和执行，正式档案保存在 [data/games](../data/games/README.md)。
- 结构化检查与状态收据见 [data/reports](../data/reports/README.md)。
