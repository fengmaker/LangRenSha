# data 目录说明

平时从 [S22 资料目录](seasons/S22/README.md)进入，先打开[中文优先复核目录](seasons/S22/S22_中文优先复核目录.csv)：有“本地全文阅读版”的条目优先打开该列，其余按“中文阅读版”打开平台字幕。其他目录主要供脚本、数据库和问题排查使用。

## 各目录的用途

| 目录 | 存什么 | 当前用途 |
| --- | --- | --- |
| `seasons/S22/` | 按周次、日期整理的音频、中文字幕、来源说明及总目录 | 日常阅读和人工复核的入口 |
| `raw/bilibili/` | 按 BV/分 P 保存的音频、原始接口响应、媒体清单和当前中文字幕 | 采集原件；脚本据此校验、重新整理和入库 |
| `raw/weibo/` | 官方微博原始帖子、完整长文响应、图片与采集清单 | 使用微博 Cookie 保存可见原件 |
| `weibo/` | 按采集日期窗口整理的全部微博、比赛排班与补充公告 | 当前看 [2026-05-26 至 2026-10-20](weibo/2026-05-26_2026-10-20/README.md)：298 条帖子、1,278 张图片、203 条完整长文，S22 52份和S23 27份排班 |
| `archive/` | 按内容哈希命名、已登记数据库的文本证据快照 | 保存不同采集版本；让数据库仍能找到登记时的原文 |
| `indexes/` | 官方合集候选索引、S22 冻结采集计划和目录缺口核查 | 确认应该采集什么；S23 索引只是未来采集线索 |
| `reports/` | 采集进度、验收、登录实测、单次采集报告和清理清单 | 查看哪些成功、哪些缺失以及执行过什么操作 |
| `diagnostics/` | 字幕可见性探测、疑似缺集视频的来源核查响应 | 排查问题和保留来源判断依据，不是比赛内容 |
| `transcripts/` | 早期 ASR、S22 样本及本轮 `{BVID}_p01_funasr_full/` 全文结果 | 本轮 25 条缺失/截短字幕音轨的全文转写已完成；保留原始模型结果和可续跑分块，本地转写与平台字幕分别保存 |
| `candidates/` | 早期根据样本转写整理的对局候选 JSON | 已入数据库的试验输入，未核验，当前不继续解析 |
| `reviews/` | 尚未完成的人工复核草稿 | 保留后续复核入口，不能当作已确认身份或结果 |

`archive/` 的哈希文件供数据库使用，不需要逐个阅读。早期候选依赖修订 ASR 样本，相关快照也被数据库引用，因此保留这些小型试验文件。PostgreSQL 的实际数据文件在项目 `.local/postgresql/`，不在 `data/` 内。

## 同一条字幕为什么有几种文件

| 后缀 | 用途 |
| --- | --- |
| `.原始.json` | 保存平台字幕内容、时间戳和其他字段，供程序处理及核对 |
| `.srt` | 标准字幕时间轴，便于配合音频定位 |
| `.阅读.txt` | 带来源和时间戳的阅读文本，人工及 AI 优先读它 |
| `.来源与命名.json` | 该媒体的官方链接、BV/CID、文件路径、哈希和命名待核事项 |

这是同一份字幕的不同用途格式，不是三份不同的转写。本轮本地全文转写使用独立的 `.本地全文转写_funasr` 后缀，在音频旁提供 JSON/SRT/阅读文本；复核目录追加“本地转写状态”“本地全文阅读版”等列，原平台字幕列保持原值。25 条的集中入口见 [全文补转写目录](seasons/S22/S22_全文补转写目录.csv)。

## 文件与空间

`seasons/S22/` 与 `raw/bilibili/` 中的音频是硬链接，指向同一份约 9.95 GB 的音频字节。两个目录分别求文件大小后相加会重复计数；不要通过其中任一入口直接编辑音频。数据库保存文件索引，不保存另一份音频。

现在只保留中文正文：`ai-zh` 是平台 AI 中文，`zh-CN`/`zh-Hans`/`zh-Hant` 等也是中文；英语、日语等翻译字幕已清除，之后采集和整理也只接受中文。原始来源响应、历史媒体清单里可能仍有平台曾报告外语轨道的元数据，这是来源记录，不是保留了外语字幕正文。

## 2026-10-20 清理结果

删除 834 个文件，共 167,707,693 字节（约 160 MiB），并删除 111 条无业务引用的外语字幕文件登记：

- 561 个不再选用的字幕整理文件，包括外语字幕和被新版本替代的中文原件/SRT/阅读文本。
- 128 个不再由当前媒体清单使用的原始字幕副本。
- 140 个外语或未登记的文本快照；其中未登记部分是早期测试遗留。
- 2 个未采到正文的微博失败清单及空目录。
- 2 个已被修订样本替代的初版 ASR 文件。
- 1 个与官方合集总索引重复的决赛周子集 CSV。

清理后保留 163 条音频、当前选用的 150 条中文字幕及仍登记的中文历史证据。当时有 12 条字幕疑似不完整、13 条未取得中文；这 25 条现已完成约 34.55 小时的本地全文补转写，结果见[补转写目录](seasons/S22/S22_全文补转写目录.csv)。平台字幕本身的缺失/截短标记继续保留。

详细删除清单和文件哈希见[本次清理记录](reports/data_cleanup_20261020T080704Z.json)；清理后的媒体与数据库验收见[S22 采集验收](reports/S22_采集验收.json)。

以后刷新字幕后，可在数据库运行时使用以下离线命令；不加 `--apply` 只预览。脚本检查目标都在项目 `data/` 内、禁止删除媒体，并保护仍登记的中文证据文件。

```powershell
.\.venv\Scripts\python.exe scripts/cleanup_data.py
.\.venv\Scripts\python.exe scripts/cleanup_data.py --apply
```
