# 来源诊断材料

本目录保存为排查来源可用性、字幕接口或媒体缺口而采集的诊断样本。

- `.json` / `.jsonl` 常包含探测响应、原始视图或字段比对结果；文件名通常说明诊断主题。
- 诊断结果只说明当次接口响应或样本状态，不自动证明完整赛季范围或长期可用性。
- 单次匿名探测未返回字幕时，应结合记录的范围和状态复核，不能直接判成“无字幕”。
- 当报告、人工结论或数据库证据引用了某份探测材料时，应连同来源上下文保留，不能按缓存清理。
- 新任务先从 [scripts/workflow.py](../../scripts/workflow.py) 查询赛季状态并预览阶段；诊断文件不作为正式档案输入。
- 采集索引在 [indexes](../indexes/README.md)，正式范围与规则快照路径保持在 `config/`。
