# 离线导出与分享

保存从当前保留源数据生成的HTML、CSV、JSON和分享包。日常从当前赛季的复核页／总目录进入，不把导出的HTML当作编辑源。

- S22最终离线复核包来自正式档案、转写和复核旁证；需要更新时运行对应导出器。
- [S21悍跳人工复核页](S21_悍跳人工复核.html)按日期逐局填写，名单和截图在前，全12席含混血儿均可选；用户自己选择悍跳人、成功结果并填写备注。页面默认无结论，浏览器自动存草稿，需导出JSON留存。
- [S23悍跳人工复核页](S23_悍跳人工复核.html)采用同一空白人工表，覆盖23个日期、75局正赛；日期、局次及12席名单取当前正式档案，截图和复盘复用已有来源，不预填旧AI判断。运行 `scripts/build_manual_bluff_review.py --season S23` 可重建。
- 2026-10-29用户提交的S23人工结果已应用到悍跳数据库：67次、10成功（含1条暂定成功），具体31项差异与入库回执见[应用报告](../reports/S23_悍跳人工复核应用_20261029.md)。人工原件在 `data/extractions/S23/bluff_review/manual_a53921fcae87.json`。
- S23逐局推导页、旧悍跳推断页和CSV来自当前候选／审计或正式专项资产；旧推断与反馈保留，重新人工复核从上述新页面进入。
- 用户从页面导出的反馈需要与来源和候选快照哈希对应；浏览器草稿未导出不等于已记录到数据库。
- 部分HTML引用同项目下的音频／截图，单独复制HTML不一定包含媒体；使用标明独立分享的包。
- 可再生文件能清理，但必须先确认生成输入和唯一反馈都已保存。
