# 离线导出与分享

保存从当前保留源数据生成的HTML、CSV、JSON和分享包。人工复核页面、待核清单和用户导出反馈统一从[人工复核目录](../manual_review/README.md)进入，页面选材与生成按[09](../../docs/09_复核页面生成规范.md)执行。

- S22最终离线复核包来自正式档案、转写和复核旁证；需要更新时运行对应导出器。
- [S21文字与截图时点索引CSV](S21_文字与截图时点索引.csv)是结构化索引的表格视图；由`prepare_s21_media_evidence.py`生成。
- [S22疑点核查HTML](S22_疑点推理复核.html)是疑点报告的浏览器视图；JSON详情与Markdown摘要保存在`data/reports/S22/`。
- 人工悍跳表按日期逐局填写，全部12席可选；由`scripts/build_manual_bluff_review.py --season ...`生成到`data/manual_review/`，浏览器草稿导出后保存至该目录的`feedback/`。
- 2026-10-29用户提交的S23人工结果已应用到悍跳数据库：67次、10成功（含1条暂定成功），具体31项差异与入库回执见[应用报告](../reports/S23/S23_悍跳人工复核应用_20261029.md)。人工原件在 `data/extractions/S23/bluff_review/manual_a53921fcae87.json`。
- S23逐局推导页和CSV来自对应候选、审计或正式专项资产；本次待核任务见[人工复核首页](../manual_review/index.html)。
- 用户从页面导出的反馈需要与来源和候选快照哈希对应；浏览器草稿未导出不等于已记录到数据库。
- 部分HTML引用同项目下的音频／截图，单独复制HTML不一定包含媒体；使用标明独立分享的包。
- 可再生文件能清理，但必须先确认生成输入和唯一反馈都已保存。

执行入口见[工作流手册](../../docs/01_赛季数据全流程.md)，源文件职责见[数据说明](../README.md)。
