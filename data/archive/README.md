# 内容寻址归档

本目录保留被数据库 artifact 系统引用的不可变快照。

- 文件名为 64 位十六进制哈希的 `.json` 文件是 DBartifact 快照；文件名承担内容寻址作用。
- 快照用于回溯数据库记录对应的原始 artifact 内容，不能重命名、覆盖或按普通缓存清理。
- 需要验证完整性时按引用的哈希校验文件字节，不要手工改写或重新序列化快照。
- `00/`、`01/` 等子目录沿用归档布局；不要依据编号推断赛季、日期或完整性。
- 需要检查来源时先从报告、数据库收据或正式档案读取 artifact 哈希，再定位对应文件。
- 赛季任务入口见 [scripts/workflow.py](../../scripts/workflow.py)；备份转储另在 [backups](../backups/README.md)。
