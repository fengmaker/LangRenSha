# 微博采集与整理材料

本目录按采集时间段整理微博来源、帖子文本、图片和核对材料。现有S22/S23映射已核实，直接复用；以后向2026-05-26以前继续采集的流程见[微博分步流程](../../docs/02_采集与座位姓名身份核实.md#确定当天出场嘉宾)。

- 日期范围目录隔离各次采集范围；`.json` 保存帖子或长文元数据，图片文件保留原始配图。
- CSV 映射表用于把来源帖子、图片和选手/事件线索联系起来；映射本身也是审计材料。
- 人工确认后的来源映射保留在清单中，不直接改写对局事实字段。
- 帖子文本、图片及其来源编号属于外部来源证据，不应作为缓存覆盖或删除。
- 与 B 站媒体的原始来源分开存放；两类材料的对应关系以清单中的来源标识为准。
- 微博采集、排班、名牌识读和照片映射独立执行，不包含在`workflow collect`中；进度和验收收据在 [reports](../reports/README.md)。
