# 单局数据库示例：固定事件模板

2026-06-25，S22正赛第四期 Day-3 第三局，机械狼通灵师。

先打开 [单局示例](单局示例.html)，或查看 [Markdown](单局示例.md)。当前结构化文件是 [dossier.json](dossier.json)。

按用户确认的口径，机械狼通灵师每夜固定8个槽位、每天固定11个槽位（含机械狼白天技能），按实际轮次重复；本局3轮，共57个槽位。夜间按守卫、狼人、女巫、猎人、机械狼、通灵师的操作展示顺序排列，女巫的解药与毒药分别记录。号码后紧跟实际身份，描述由模板生成。

机械狼学习当夜不能使用新技能；机械猎人紧接着的白天可用，其他夜间形态从下一夜可用。机械双刀狼另须等其他狼人全出局、带刀后才可发动技能刀；技能刀无视守卫的盾。本局第2、3夜仍有普通狼人，所以技能刀均未解锁。女巫毒药命中机械守卫盾时结算为女巫死亡，原目标不因该毒药死亡；当前示例没有发生此交互，规则由专项测试覆盖。

每夜保留“机械狼带刀确认”槽位。本局三夜均未带刀：第1夜3、6、12号狼人仍在场，第2夜3、6号狼人仍在场，第3夜3号狼人仍在场。8号机械狼在第三天先被猎人带走，随后3号狼人自爆，因而本局没有带刀夜。

人物统一登记在 `people`；本局解说为其人、桃子，法官为豆儿啵。选手、解说、法官是本局职责，同一人物可以在其他对局担任选手。常见法官豆儿啵、辉少均已登记。

座位映射采用2026-06-25第一局 BV1Pt7v6XEP4 的自我介绍及用户确认，12个座位姓名已完整对应：7号JY、9号翼风、11号申屠、12号陈俊洁。JY在场时固定为7号，此规则会在导入时校验。

第一天发言为警上发言：随机点数3，3号未上警，沿顺序方向跳到4号平民开始；第二天没有发言环节；第三天随机点数11，从11号平民开始顺序发言。随机点数、发言范围和实际起点分别保存。

猎人技能由用毒情况计算：被女巫或机械女巫毒药命中时不能开枪，未中毒时可以开枪；已在之前轮次出局的猎人不再参与后续夜间操作。本局三夜7号猎人均可以开枪。

当前业务表为 `game_details`、`game_seats`、`game_staff`、`game_rounds`、`game_event_records`、`game_event_targets`、`game_event_votes`，分别保存基本信息、座位、职责、轮次、事件、目标和票型。源文件仍由 `sources` / `artifacts` 登记，`game_files` 选择本局各类当前文件。事件描述从结构化字段生成，不在库中重复保存整句。

当前业务结构没有证据、完整转写片段、版本或审核状态。转写仅作为源文件登记一个当前文件入口。此前的 `dossier.v1.json`、带“候选”的CSV及旧数据库提取/审核表属于早期试验记录，不再用于当前导入。原始文件没有删除。
