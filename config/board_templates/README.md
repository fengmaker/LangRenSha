# 版型事件模板

每个JSON定义一种版型的身份数量、每夜／每天固定槽位、行动者与允许动作。模板用于结构，不自动证明真实叫醒顺序或某局实际行动。

- 无赛季前缀的文件主要是原S22模板，包括正式计分与归档用娱乐版型。是否进入统计由该季范围／正式规则决定，不能看模板存在就纳入。
- `s23_*.json`是S23独立模板；同名版型在本季的首夜、角色或动作差异不能改写S22模板。
- `s21_*.json`承接S21已核事件，按本版实际观察的动作设置归档槽位；未确认的角色数量保留空值，未确认的叫醒顺序保留空列表，不套用其他季规则。
- 底牌、学习／榜样／傀儡／面具状态分别记录；操作目标与实际结算分开。
- 模板已被正式档案和数据库枚举引用。更改需要同步规则、校验、导入和发布，并保存新旧版本；不批量重命名已引用代码。

入口见[配置说明](../README.md)及[字段证据规范](../../docs/16_字段证据与交叉复核规范.md)。
