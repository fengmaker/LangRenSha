# 版型事件模板

每个JSON定义一种版型的身份数量、每夜／每天固定槽位、行动者与允许动作。模板用于结构，不自动证明真实叫醒顺序或某局实际行动。

- 每个版型只保留一个无赛季前缀文件，基础身份和同版型能力共用。是否进入正式统计由 `seasons.json` 的范围决定，不能看模板存在就纳入。
- `storage_variants` 兼容数据库和档案中已有的 `s21_*`、`s23_*` 代码，只保存与共同结构不同的字段、槽位代码顺序和槽位覆盖；通过 `scripts/board_config.py` 的 `load_template` 读取，不直接拼接旧代码文件名。
- S21的稀疏已核事件槽、未知身份数量和未核夜序是归档证据差异，不代表基础玩法不同。机械狼技能形态集中共用；假面的角色替代、盗宝大师单局DQ动作等保留现有存储表达。
- 底牌、学习／榜样／傀儡／面具状态分别记录；操作目标与实际结算分开。
- 槽位列表表达归档位置，玩法能力见共同 `game_rules.json`。确有规则改版时只登记对应差异及证据，不复制整份赛季模板。
- 旧模板原始字节及路径、哈希对照见[历史快照](../../data/extractions/shared/config_history/2026-10-29/README.md)；原数据库代码继续可读。
