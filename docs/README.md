## 最小复核协议

1. 先固定来源和规则版本，再读连续原句／画面；平台字幕与多份机器稿不能代替真实证据。
2. 分开底牌与自称、原目标与实际效果、实际死亡与公布时点、理论条件与真实结算。
3. 按真实时序前向重放存活和票权，再用后续发言、出局和终局复盘后向核对。
4. 因果唯一才记推断，保留前提；多解时问具体问题，资料缺失继续未知。
5. 原件、推断、用户确认和正式事实分别保存；改动后沿依赖重查并更新入库／发布回执。

01、03—07、10及archive中包含早期阶段记录，里面的“当前／后续”按当时日期理解；需要执行时使用15的统一入口。正式规则文件及来源快照的哈希不因文档整理而改变。
