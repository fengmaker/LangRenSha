## 结论

目前不能称现用 ASR“开源最佳”，也不能给出项目准确率。开源描述代码/权重和许可，不等同于质量排名。Whisper large-v3 与 Qwen3-ASR 已有官方发布，可以作为两种强候选，与当前 base 基线在本项目音频上实测；SenseVoiceSmall 可列为中文向后续候选。

没有人工逐字真值集之前，不能把模型卡或论文中其他公开数据集结果换算成本项目准确率。

faster-whisper 是 Whisper 的推理实现/引擎，不是独立训练模型权重。其官方模型映射将 base 指向 Systran/faster-whisper-base；该权重卡标 MIT，并说明其由 openai/whisper-base 转换而来。OpenAI README 也声明 Whisper 代码和原始权重为 MIT。若要确认当前安装的精确模型来源，仍应记录实际缓存仓库和 revision。当前应描述为：

> faster-whisper 1.2.1 推理引擎 + Whisper base multilingual 权重 + CPU INT8

更换到 large-v3 主要更换模型权重/规模；换到 Qwen3-ASR 则模型和推理栈都变化。比较时应记录模型权重、推理引擎、参数和量化精度。

## 可考虑的开放模型

### 1. Whisper large-v3

**一手来源**

- [OpenAI Whisper 官方模型卡（源仓库）](https://github.com/openai/whisper/blob/main/model-card.md)
- [OpenAI 名下 large-v3 模型卡](https://huggingface.co/openai/whisper-large-v3)
- [Whisper 架构与初代模型论文（不是 large-v3 专属评测）](https://cdn.openai.com/papers/whisper.pdf)
- [词级时间戳实现](https://github.com/openai/whisper/blob/main/whisper/transcribe.py)

**核验结果**

- 多语言模型；HF 模型卡标注 99 种语言。参数约 1.55B，multilingual base 为 74M。
- Whisper 有分段时间戳；启用 `word_timestamps` 才请求词级时间戳，时间为模型估计。
- 官方卡片报告其对口音、背景噪声、技术语言有总体鲁棒性，但也指出语言间表现不均、可能幻听未说内容、重复文本。不能据此保证本项目的玩家姓名、游戏术语、票数准确。
- 未找到本工作站的最低内存保证。相较 base，大模型 CPU 延迟和内存需本机测试。
- OpenAI 上游 README 声明 Whisper 代码和原始权重为 MIT；但 HF 的 openai/whisper-large-v3 checkpoint 页面元数据标注 Apache-2.0。两处标签不一致，使用/再分发前应核实具体 checkpoint 所带许可证与版本，不作未经核实的许可推断。

**定位**：强基准候选。可先沿用现有 faster-whisper/CTranslate2 运行路径，减少引擎变化。

### 2. Qwen3-ASR-1.7B

**一手来源**

- [Qwen 团队官方仓库](https://github.com/QwenLM/Qwen3-ASR)
- [Qwen3-ASR 技术报告](https://arxiv.org/abs/2601.21337)
- [Qwen3-ASR-1.7B 模型卡](https://huggingface.co/Qwen/Qwen3-ASR-1.7B)
- [Qwen3-ForcedAligner-0.6B 模型卡](https://huggingface.co/Qwen/Qwen3-ForcedAligner-0.6B)

**核验结果**

- 确有官方发布；模型家族含 1.7B 与 0.6B。仓库列出普通话 `zh`、粤语和多种中文方言，支持离线/流式 ASR。
- Qwen 团队声称模型可处理复杂声学环境；这是其发布方介绍和基准结果，不是对本赛事录音的准确率保证。
- ASR 本体要时间戳时需另配 ForcedAligner；官方说明它覆盖 11 种语言，单次最长对齐 5 分钟语音。长音频需分段后对齐。
- 仓库和模型卡列 Apache-2.0。官方 Transformers 示例采用 CUDA/BF16；另有 vLLM 后端，并建议在兼容硬件上用 FlashAttention 2。
- 示例配置不是最低显存承诺；若考虑 CPU，须测吞吐和内存。模型载入会下载权重，试验前确认本地环境与存储。

**定位**：强候选。重点检查方言、混响/多人声、游戏专名和投票数字。

### 3. SenseVoiceSmall（可选扩展）

**一手来源**

- [SenseVoice 官方中文 README](https://github.com/QwenAudio/SenseVoice/blob/main/README_zh.md)
- [SenseVoiceSmall 官方权重模型卡](https://huggingface.co/FunAudioLLM/SenseVoiceSmall)
- [FunASR 权重许可协议](https://github.com/modelscope/FunASR/blob/main/MODEL_LICENSE)

**核验结果**

- 官方 README 列出的已发布 checkpoint 支持中文、粤语、英文、日文、韩文 ASR 与语种识别。
- README 提供词与毫秒级时间戳输出示例；长录音需 VAD/分段或有界窗口，固定切片边界附近可能影响识别。
- SenseVoiceSmall checkpoint 本身不输出说话人身份；FunASR 生态可组合独立 VAD/CAM++ 做说话人分段。
- 仓库代码为 MIT；模型权重另适用 FunASR Model Open Source License Agreement v1.1，要求保留来源/作者信息和模型名。不能把代码许可证套用到权重。
- 官方文档有 CUDA 用法，也列出 CPU 容器/GGUF 路径；实际速度和内存仍需本机测量。

**定位**：中文向第三候选；首轮不必增加，避免扩展评测面。

## 开源与准确率的证据边界

官方模型卡里的评测只能说明发布方在特定数据集、任务、文本归一化和软件配置下的结果。不同数据集之间的 CER/WER 不能直接横比；不使用第三方榜单宣布绝对第一。

项目目前没有人工逐字转写真值，因而没有可报告的 CER、WER、专名正确率或投票数字正确率。现有几分钟中的错专名、术语、票数可作为错误类型线索，不能用来估计整体准确率。

中文字符错误率（CER）和分词后词错误率（WER）依赖不同规则；若报告 WER 必须公开分词方式。不要把人名、游戏术语和数字在归一化时删掉或改成宽泛占位符。

模型转写可能漏字、幻听或重复。多人重叠、背景解说、音效、低声发言需要单独分层查看。ASR 文本不能独立证明身份、阵营或个人输赢；这类事实要对照角色揭晓、结算画面或可靠官方资料人工核实。

## 本项目最小对比设计

如果人工复核证明现有模型存在明显瓶颈，再考虑比较三条流水线：

1. **基线**：当前 faster-whisper 1.2.1 + multilingual Whisper base + CPU INT8。
2. **强候选 A**：Whisper large-v3；尽量沿用 faster-whisper/CTranslate2，同步记录转换权重来源、模型 revision、精度/量化。
3. **强候选 B**：Qwen3-ASR-1.7B，固定官方 `qwen-asr` Transformers 后端或固定版本 vLLM。ASR 文本和 ForcedAligner 时间戳分开测。

SenseVoiceSmall 可作为后续第四条，不加入首轮主比较。

### 采样与人工真值

- 选取同一批获准使用的赛事音频片段；先人工标注累计约 30–60 分钟，覆盖清晰单人、噪声/混响、多人重叠、专名/游戏术语、含票数的片段。
- 该时长是小规模评测设计建议，不是充分样本量或准确率承诺。
- 人工逐字转录；听不清处标注时间范围和“不可辨”类别。至少第二人复核人名、数字和争议片段，保留音频时间码及最终真值版本。
- 切片、声道处理、采样率和响度策略保持一致；不为单一模型手工清理音频或修改输出。
- 固定语言设置、VAD、窗口切片、解码参数；若某模型不支持相同设置，明确记下差异。未来若热词提示/微调，必须与封存评测集分离。

### 指标

**全文转写**

- 按固定的简繁、标点、空格和数字书写规范算中文 CER。
- WER 仅作为有明示分词器/分词规则的补充指标。
- 不归一化掉专名、领域术语、票数和座位号。

**项目关键内容**

- 建立独立 gold list，统计专名/术语逐项准确率与召回率。
- 单独统计投票数、座位号、轮次数字 exact match。
- 按清晰/噪声/重叠等条件分层，列样本数和典型错例；小样本只描述本批数据，不外推到整季。

**座位、角色与结果**

- 独立由人工根据角色卡/终局揭晓、结算画面建立逐座位真值；不能用 ASR 输出本身充当身份真值。
- 对模型辅助生成的结构化候选，在人工更正前测座位、昵称、开局角色/阵营、结算身份、个人结果各字段的精确率/召回率及整条记录 exact match。
- 最终人工核验记录用于数据库；不要把人工更正后的值回计为模型识别准确率。

**时间戳与运行开销**

- 若产品需要逐句/逐词时间，单独人工标注时间边界并测偏差分布；不同模型的时间粒度必须映射到同一评测定义。
- Qwen ForcedAligner 单次限 5 分钟，需按约束分段并单独检查边界；Whisper 词级时间是估计。
- 保存权重名/revision、引擎版本、语言、量化、VAD/切片、解码设置、设备/线程、耗时和 RAM/VRAM 峰值。硬件结果只用于判断现有设备是否可运行，不据此建议购买设备。
