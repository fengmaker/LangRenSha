# B 站认证与采集命令说明

> 历史参考：本文件保留此前方案与试验过程。当前执行范围以 [项目入口](../../../README.md) 和 [三步路线](../../01_项目路线.md) 为准；当前只推进第一步原始媒体采集。旧文中的“下一步”不作为当前任务。

## 依赖

采集入口依赖 `requests`，可在项目环境中安装：

```powershell
python -m pip install -r requirements/collection.txt
```

只有需要运行可见浏览器登录助手时才需要 Playwright 和本机已安装的 Microsoft Edge 或 Google Chrome：

```powershell
python -m pip install playwright
```

登录助手通过 Playwright 的 `msedge` 或 `chrome` channel 启动已安装的浏览器。它使用项目 `.secrets` 下单独的持久 profile，不连接、读取或接管其他 Chrome/Edge profile，也不读取 MediaCrawler 登录态。

## 匿名采集

默认 `--auth none`，不会读取浏览器会话或 Cookie 文件。下面两条命令都以匿名模式运行；第二条显式写出默认值：

```powershell
python scripts/collect_bilibili_audio.py BV1tj8p6REqy
python scripts/collect_bilibili_audio.py --auth none BV1tj8p6REqy
```

匿名模式只获取接口在本次请求中可见的元数据和字幕轨。若需下载独立音轨，仍要显式指定 `--audio`。

## 先登录，再显式带 Cookie 采集

用户主动启动登录助手，并选择一个已安装的浏览器：

```powershell
python scripts/login_session.py bilibili --channel msedge
```

助手会打开 B 站页面。请在可见浏览器中自行正常登录，完成后回到终端按 Enter。助手只筛选 B 站域名的未过期 Cookie，并写入 `.secrets/bilibili.cookies.txt`；持久 profile 位于 `.secrets/browser-profile-bilibili-msedge`。需要 Chrome 时将 `--channel msedge` 改为 `--channel chrome`。

之后必须显式选择 Cookie 模式和文件：

```powershell
python scripts/collect_bilibili_audio.py --auth cookies --cookies-file .secrets/bilibili.cookies.txt BV1tj8p6REqy
```

如果同时需要独立音轨，可以加 `--audio`：

```powershell
python scripts/collect_bilibili_audio.py --auth cookies --cookies-file .secrets/bilibili.cookies.txt --audio BV1tj8p6REqy
```

Cookie 文件等同密码，应限制本机访问并避免提交到版本库，也不要把 Cookie 发到聊天或粘贴到命令行。助手不会绕过验证码或访问限制；验证码如出现，由用户在正常浏览器流程中自行处理。它只导出浏览器提供的 Cookie，不验证登录是否成功，也不保证账号对目标视频、字幕或音轨有权限。

采集 manifest 只记录认证模式和是否加载了 Cookie，不写 Cookie 值或 Cookie 文件路径。若接口仍返回 `need_login_subtitle: true`，字幕状态继续记为 `login_required`，并标明 Cookie 已加载但登录要求仍存在；这表示会话可能无效，或账号权限仍不足。每条字幕轨保留平台给出的字段，不据此推断人工或 AI 来源。

`scripts/auth_support.py` 的公共入口为 `configure_session(session, auth_mode='none', cookies_file=None, platform='bilibili')`。当前允许 `bilibili`、`douyin`、`weibo`，`none` 模式完全不读取 Cookie 文件；`cookies` 模式仅接受 Netscape 格式文件中属于所选平台且未过期的 Cookie。
