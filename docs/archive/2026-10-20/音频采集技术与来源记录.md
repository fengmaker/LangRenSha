## 结论摘要

- yt-dlp 官方 README 支持通过 `-f bestaudio` 选择音频流，并用 `-x --audio-format m4a` 抽取/转换为音频文件；该转换依赖 FFmpeg 与 FFprobe。可先用 `--list-subs` 检查视频提供的字幕，再用 `--write-subs` 下载已存在的字幕。默认不下载自动生成字幕；`--write-auto-subs` 是独立选项。
- OpenAI Whisper 支持多语言语音识别，代码中包含中文 `zh`；提供分段起止时间，且可开启实验性的词级时间戳。faster-whisper 有同样可用的分段/词级时间戳接口。两者的基础转写结果都不等于说话人分离。
- WhisperX 在 Whisper/faster-whisper 转写和对齐基础上集成说话人 diarization，可输出 speaker ID；官方 README 说明该功能需要 Hugging Face 访问令牌并接受所用 pyannote 模型的条款。speaker ID 不是现实人物姓名识别，仍须人工校对。
- 找到三条搜索索引显示由“京城大师赛官方”发布的候选视频。直接打开 B 站视频页均返回 Internal Error；以下只能报告索引可见元数据，不能宣称看过画面/听过音频、核验逐局内容或确认实际音轨、字幕。

## yt-dlp：音频 only 与既有字幕

来源：yt-dlp 官方仓库 README  
链接：[yt-dlp README — Subtitle Options / Post-Processing Options](https://github.com/yt-dlp/yt-dlp/blob/master/README.md?plain=1)  
访问日期：2026-10-20  
状态：已核验（官方文档）

文档列出 `--list-subs`（列出可用字幕）、`--write-subs`（下载字幕文件）、`--write-auto-subs`（下载自动生成字幕），并区分默认不写字幕/自动字幕。可用语言标签应先由 `--list-subs` 查看。文档同时列出 `-x, --extract-audio` 将视频转换为仅音频文件，支持 m4a 等格式，且标明需要 ffmpeg/ffprobe。

建议先检查一个投稿的真实字幕列表：

```powershell
yt-dlp --list-subs "https://www.bilibili.com/video/BV1dc836KEjJ/"
```

如列表确实有中文字幕，按输出的实际语言标签替换下面的 `zh-Hans`（标签不匹配时不会凭空生成字幕）：

```powershell
yt-dlp --skip-download --write-subs --sub-langs "zh-Hans" --sub-format "srt/ass/best" "https://www.bilibili.com/video/BV1dc836KEjJ/"
```

若想同时看可用格式与字幕，可用：

```powershell
yt-dlp --list-formats --list-subs "https://www.bilibili.com/video/BV1dc836KEjJ/"
```

音频 only 建议参数：

```powershell
yt-dlp -f "bestaudio" -x --audio-format m4a "https://www.bilibili.com/video/BV1dc836KEjJ/"
```

以上会选择最佳音频流并由 FFmpeg 抽取/转换为 m4a，不选择画面流；需要本机可调用的 ffmpeg 和 ffprobe。命令是依据官方参数给出的可执行方案，本次没有实际运行或下载。

## 本地语音识别与时间/说话人标注边界

### OpenAI Whisper

- [OpenAI Whisper 官方仓库 README](https://github.com/openai/whisper/blob/main/README.md?plain=1)，访问日期 2026-10-20，已核验：说明 Whisper 是多任务、多语言语音识别模型。
- [官方 tokenizer 语言表](https://github.com/openai/whisper/blob/main/whisper/tokenizer.py)，访问日期 2026-10-20，已核验：包含 `zh: chinese`。
- [官方 transcribe.py](https://github.com/openai/whisper/blob/main/whisper/transcribe.py)，访问日期 2026-10-20，已核验：结果包含带起止时间的 segment；`word_timestamps=True` 可请求词级时间戳，源码将其描述为通过 cross-attention 与 dynamic time warping 提取，属估计时间。

可执行示例（需先安装 Whisper 模型依赖及 FFmpeg）：

```powershell
whisper recording.m4a --language Chinese --task transcribe --word_timestamps True --output_format json
```

### faster-whisper

- [SYSTRAN faster-whisper 官方仓库](https://github.com/SYSTRAN/faster-whisper)，访问日期 2026-10-20，已核验：README 演示本地 `WhisperModel`，输出分段 `start/end/text`；`word_timestamps=True` 时输出逐词起止时间。README 也列出 CPU INT8 与 GPU 等运行方式。
- 中文支持由其所基于的 Whisper 多语言模型提供；本次查到的 faster-whisper README 示例本身未列全语言表。以 [OpenAI Whisper 的中文语言代码](https://github.com/openai/whisper/blob/main/whisper/tokenizer.py)作为模型能力的一手依据，不把它等同于对具体音频转写质量的保证。

### 说话人区分

- [WhisperX 官方 README](https://github.com/m-bain/whisperX/blob/main/README.md?plain=1)，访问日期 2026-10-20，已核验：说明其提供词级时间戳和 speaker diarization，并明确基础 Whisper 的时间戳通常是话语级、可能与实际音频有数秒偏差。README 的说话人分离步骤要求 Hugging Face read token，并接受 pyannote speaker-diarization-community-1 模型条款。
- [WhisperX speaker assignment 源码](https://github.com/m-bain/whisperX/blob/main/whisperx/diarize.py)，访问日期 2026-10-20，已核验：将 diarization 时间区间与转写区间重叠后分配 speaker ID。该机制给出的是声纹/区间聚类标签，不能据此自动确认选手姓名。
- 对多人同时说话、背景音、解说与玩家声音重叠的局面，转写与 speaker ID 都应视作待人工校正的候选标注。未对本赛事音频做准确率测试。
