## 先交付什么

1. 原音频中的完整复盘片段，保留少量前后缓冲，能直接回听。
2. 逐字机器转写与仅整理标点的阅读稿，分别保留来源和修改依据。
3. 12 座身份表、逐夜行动表和胜负候选，每项附对应时间及原文；未清楚识别的字词单列。
4. 与平台字幕的差异清单，集中复听数字、否定词、目标、角色与行动顺序。

仅有模型一致或文字通顺，不等于已听核正确。未经人工或其他可靠证据核对的结果保持待审核，不把推理补齐写成法官原话。

## 身份列表必须连续读取

例如相邻字幕写成「通灵师 / 一号女巫 / 十号猎人 / 七号守卫 / 五号」，连起来可能是「通灵师一号、女巫十号、猎人七号、守卫五号」。字幕断行不能直接当作字段边界。

身份、角色名称、行动人与目标均需要逐字对齐。逻辑校验用于发现疑点，不能用“这局应该这样发生”去改写听不清的内容。复盘明说平民座位才记为揭晓；按剩余座位推导的结果必须另标推导。

## 转写之后的处理

后续优先流程：平台字幕定位复盘（缺字幕时局部音频扫描）→ 裁出复盘或所在几分钟 → 清楚转写该段 → 提取全员身份与逐夜信息 → 核对 → 按需补充局中细节与观点。

首个试跑为验证完整链路，曾先转写整条37分钟音频，再精确提取复盘；后续不需要重复这一步。

“本局信息”与“发言切分”分别验收。AI 可以先利用复盘建立身份与夜间经过，再回看玩家发言；无需先把每一句话都正确分到某个玩家，才开始理解这一局。

| 信息 | 优先证据 | 不能直接替代的内容 |
| --- | --- | --- |
| 实际身份与胜负 | 法官最终复盘、明确揭晓或结算 | 玩家跳身份、解说猜测 |
| 夜间实际行动 | 法官逐夜复盘及明确结果播报 | 夜间解说的刀口猜测、条件假设 |
| 玩家知道什么、说过什么 | 该玩家当时的完整发言及发言权证据 | 赛后已知身份倒推其当时信息 |
| 票型、发言顺序、具体措辞 | 局中明确播报、发言原文或后续画面 | 概括性复盘中未提及的细节 |
| 解说当时的判断 | 解说原文及当时对局阶段 | 事后正确结果替换当时判断 |

## 夜间与解说是两条并行记录

对局阶段可以是夜间，同时节目中有解说分析。分别记录“场上到了哪一步”“谁在说话”“内容属于分析还是实际结果”。解说、法官、场上玩家、主持和未知属于说话者角色；赛前互动、局中分析、法官复盘、采访等属于内容类型，同一人可以参与不同内容。

法官指令是归属场上玩家发言的重要证据。原音频中可能有明确指令，但 ASR 没识别出来；不能据此把后续全部内容归为解说。未知保持未知，先不强制归号。

## 后续批量只转写短窗口

1. 对已有平台字幕检索整条时间轴的复盘开场、连续身份清单、夜间行动及收尾。复盘可以在文件中段，不能一律认定在最后五分钟。
2. 线索充分时裁取带缓冲的复盘候选窗口，一般几十秒至几分钟；边界有疑问时多留上下文。实际批量可以转写复盘所在的1–3分钟，再从结果中提取复盘正文，避免首尾截得过紧。
3. 没有字幕、字幕截短或没找到可靠位置时，先扫末尾5分钟；未找到则扩大至10、20分钟，仍不足时进入定位复核，避免默认整条转写。
4. AI从连续复盘提取12座身份、模仿目标、逐夜行动与结算，并校验座位是否遗漏/重复。身份名称、原始身份与学习结果分别保留。
5. 命中多个候选、只有一半身份或没有结束语时，保留异常；不把关键词命中或一次解说分析视为已正确定位。
