# 通用增量更新流程

## 窗口触发指令

用户说“增量更新”时，在当前窗口按本流程做到新增对局人工复核页。用户已说明采集完成则从资料核验开始。分析由当前窗口选择的模型直接完成，不通过 Codex CLI 或另起模型调用；写入最终数据、导出、上线、提交和推送按用户另行明确范围执行。

## 采集与准备

```powershell
.\.venv\Scripts\python.exe scripts/workflow.py run --season S23 --stage collect
.\.venv\Scripts\python.exe scripts/workflow.py run --season S23 --stage process
```

采集仍有计划预览/确认；使用已有认证设置。已完成来源以最终 `game.json` 为准，旧原件不存在不触发重采。当前队列保存在 `data/reports/<赛季>/incremental/state.json`；每局临时资料放在 `data/extractions/<赛季>/incremental/<BV>_pNN_cid<CID>/`。

处理优先复用中文字幕；确实没有可用中文文字才转写音频。主 Paraformer 模型保留；第二模型复听和旧横评链退役。`input.json` 和 `reading.txt` 是本批输入，不是长期资料。

## 当前窗口整理

当前窗口完整阅读本局资料，核实座位、姓名、底牌、个人阵营、日夜事件、每轮逐人票型及终局，保存 `candidate.json`。候选沿用 `input.json` 的 dossier/voting 结构、slug、赛季、版型和来源 files；按需要附独立 endgame。证据字段按[字段规范](02_字段证据与交叉复核规范.md)，只绑定本局来源，未知保持未知。规则资格由共用规则计算，不能当作实际行动证据。

按[生成规范](09_复核页面生成规范.md)选身份截图与连续复盘区间，保存 `review_display.json`。截图用 `capture_bilibili_frame.py` 按实际定位取源。然后执行：

```powershell
.\.venv\Scripts\python.exe scripts/workflow.py run --season S23 --stage review
```

此命令校验候选版本、原文和字段关联，为本批生成 `data/manual_review/<赛季>_新增对局人工复核.html`。页面内嵌必要图片和复盘片段，用户逐局确认并选择悍跳人及是否成功。与网站档案共用 `game_timeline.py`；网站不提供公开证据复核和反馈工具。

## 确认与最终结果

用户导出复核 JSON 后先预检：

```powershell
.\.venv\Scripts\python.exe scripts/apply_incremental_review.py <复核JSON> --season S23
```

自由备注需由当前窗口解释成 `masters-incremental-note-revisions-v1` 修订文件，绑定 review_id、candidate_sha256、source_sha256 和原备注；games 中每条包含 patches、unresolved、bluffs。patches 使用指向现有 dossier/voting 字段的 JSON Pointer，附 value、note_quote 和 reason；无法唯一理解时填 unresolved。通过 `--note-revisions` 交给同一预检命令，未解决项禁止应用。

备注明确将成功结果保留为待定时，该悍跳条目写 `success: null, success_selected: true`；没有填写成功结果则用 `success_selected: false`，两者不能混用。

明确获准写入后：

```powershell
.\.venv\Scripts\python.exe scripts/workflow.py run --season S23 --stage finalize --review-export <复核JSON>
```

将确认后的身份、事件、票型、终局、规则结算和悍跳结果固化为每局一份 `game.json`。人工成功/失败/待定选择优先；未填写悍跳不等于无人悍跳。只处理选中局，已写入的同版本可续跑，不同版本不得静默覆盖。

## 本地网站与结束

```powershell
.\.venv\Scripts\python.exe scripts/workflow.py run --season S23 --stage export
.\.venv\Scripts\python.exe website/run.py
```

本地从全部正式数据直接导出，跨季统计保留已有范围。按本批对局和受影响选手验证；不重新分析整季，不生成整套历史副本或验收回执。照片准备以现有照片清单为基线，仅补本批新增选手。

本批完成后，保留 `game.json`、必要来源定位和新增正式照片；临时截图、全文、候选、推断、复核页和已处理反馈可删除。清理前将完成的微博日期区间和帖子 ID/日期并入 `data/sources/weibo_checkpoint.json`，保留增量发现能力。当前尚未完成的批次材料继续保留，不能按目录年代批量删除。

静态成品构建、同步与上线只按明确请求执行。参见[发布说明](../website/static_publish/README.md)。
