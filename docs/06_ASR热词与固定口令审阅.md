# ASR 热词与固定口令审阅

审阅日期：2026-10-22。

本轮把全文默认词表从 **34 词扩到 342 个唯一词条**，复盘专用词表从 **29 词扩到 261 个唯一词条**。原有词条全部保留。词条包含短术语和固定短语，按空白分隔计数，不按汉字数或词条中的子词重复计数。

## 语料与方法

扫描 `data/transcripts/S22/*/transcript.json` 中的全部 27 份顶层转写：25 条已完成全文补转写，加此前的长、短样本，共 **70,067 个片段、711,815 个文本字符，约 37.55 小时音频**。另外对短样本的 52 秒法官复盘原稿做上下文复核；它已包含在完整短样本中，不重复计入统计。未把 `raw/`、二次转写、TXT/SRT 导出和音频旁的副本重复计入。

对全部文本做重复短语扫描和候选命中统计，再定向抽查开场、发言权交接、投票、夜间技能与最终复盘。板型名同时核对本季[中文优先复核目录](../data/seasons/S22/S22_中文优先复核目录.csv)的原始标题。此过程是文本审阅，未逐段回听音频。

逐词依据保存在[机器可读审阅报告](../data/reports/S22_ASR热词扩充审阅_2026-10-22.json)，包括两表分组、文件哈希、命中次数、覆盖文件数、BVID、音频时间和原文。默认表中 **299/342** 个词、复盘表中 **222/261** 个词有逐片段精确子串命中；没有精确命中的词条单独列出依据，包含来源标题中的板名和规范短语候选。精确命中只说明机器稿出现过该字符串，不能据此认定识别或游戏规则正确。短语被分成相邻片段时，这种统计也可能漏计。

## 异文与取舍

- 短样本 `BV1yt7v6QE3Q` 00:33:59—00:34:44 中有“神神阵银”“警上进尾环节”“延期竞尾环节”“女巫技能通过”“四手”等异文。词表补入或保留“神职阵营、警上竞选、延期竞选环节、女巫技能空过、自守”等规范候选；本轮没有按上下文改写原稿。这些候选还需要回听，已由此前用户确认的“空过、自守”释义见 `CONTEXT.md`。
- “首夜”附近多次出现“首页/首位”等机器异文，“弹幕老师”也存在“大老师”等异文。增加规范词与短语，不把这些异文作为替换规则。
- “舞者/武者”不凭机器稿的语义猜测定名。默认采用多份稿中已有的“舞者”；另参考[规则发布者的假面舞会角色说明](https://werewolves.games/jia-mian-wu-hui/)核对“舞者、假面”的拼写。这里只交叉核名，不把该站的规则版本当作本赛事规则。
- 本季标题可确认“唯邻是从、鬼魂新娘”等板名，但这些局没有进入本轮 25 条全文补转写，不能由板名推导其角色配置。
- 诡术之境稿中“魔术师”和“鬼术师”有不同角色语境，不能直接合并。后者及“定血王子/定绪王子”等同音称谓仍待原始规则图或听音核对，本轮不加入这些推测拼写。其他仅在早期解析器正则出现、缺乏本轮语料依据的罕见角色也不为凑数加入。
- “爆水/排水”虽然多次出现，仍可能涉及“表水”或其他表达的异文，本轮保持待核。热词库不会把同音词自动统一。

## 使用与验证

全文默认加载[默认热词表](../config/asr_hotwords.txt)。需要复盘词表时，在原转写命令中显式加入：

```powershell
--hotwords config/asr_recap_hotwords.txt
```

这是替换本次运行使用的词表，不是与默认表合并；两份文件均可独立使用。`transcribe_funasr.py` 会将实际词条写入新运行的 `config.json`，便于追溯。

已使用本地 FunASR 1.4.16 的真实 `SeacoParaformer.generate_hotwords_list`、`CharTokenizer` 和已下载模型的 `tokens.json/seg_dict` 做离线检查：两份文件分别完整解析出 342 和 261 个热词，没有未知 token、空词或重复词，原有词条全部保留；模型附加的起始 token 不计入词条数。

扩词阶段只做解析检查，未重跑音频。原有 25 条批处理结果和配置保持原样，仍记录旧版 34 词词表。同一输出目录的配置不匹配时，现有脚本会拒绝覆盖，需要为新版本选择新的输出目录。

## 随后进行的单音频试跑

2026-10-22 按用户要求，完整重跑了 37 分钟标准样本 `BV1yt7v6QE3Q`。实际快照为当前 **343 词**版本（较上述 342 词审阅多了“定序王子”），与旧 34 词版本比较；模型、依赖、说话人流程及保存的 VAD 边界相同，配置唯一变化是热词。
