# 版型规则与模板维护

先固定实际版型和正式范围，复用已确认的基础身份与同版型规则。2026-10-29用户确认基础规则通用、同版型能力跨季共用；季配置未重复列出不是规则失效依据。有证据的实际改版才覆盖相应字段，单局裁定仍保留其作用域。执行与推导明细见[通用规则推导](07_通用规则推导.md)。

## 规则入口

| 入口 | 用途与边界 |
| --- | --- |
| [赛季注册表](../config/seasons.json) | 运行期来源与适配入口；`scope` 保存正式／表演／娱乐范围、快照和排除项，`formal_import` 保存局数、轮换及导入设置 |
| [共同规则](../config/game_rules.json) | `field_definitions`、`shared_rules`、`boards` 集中维护字段、基础身份及同版型能力，不按赛季重复定义 |
| [案例规则](../config/game_rules.json) | `review_rules.rules` 保留来源、状态与作用域；已确认的共同规则跨季复用，单局裁定仍只作用于该局 |
| [版型模板目录](../config/board_templates/README.md) | 身份数量、固定事件槽、合法动作、目标及已核 `wake_order` |
| [共有约定](../config/game_rules.json) | 已实现的固定座位、机械狼等约定，使用前核适用范围 |
| [计分配置](../config/game_rules.json) | `scoring` 保存共同计分与赛制、用户报告来源及未决项；明确差异局部登记，不声称全部官方验证 |

规则证据查[官源原图](../data/raw/rules/weibo_5228857471013279/README.md)、[研究索引](research/README.md)及当局法官裁定。证据冲突按[字段规范](02_字段证据与交叉复核规范.md#6-冲突与修订闭环)处理，保留未知与局部例外。

## 模板表达什么

固定槽是归档位置。法官叫醒顺序、技能何时可用、实际结算顺序分别核实；只有已确认的 `wake_order` 表示操作顺序，空列表不靠槽位顺序补齐。白天技能按实际时点发生，槽位排在最后不表示最后发动。

底牌、榜样／学习／傀儡／面具等状态分开；傀儡不是第13张身份牌，动态余牌不硬套固定角色数。首夜专属、次夜解锁、资源耗尽、已出局、明确空过、规则禁止与资料未知分别记录。

状态词遵从现有消费者：通用核实记录、S22正式事件和S23专项文件不一定使用同一枚举。例如S22槽位中的 `unavailable` 与S23首夜禁刀的 `forbidden` 不能为了统一文字批量改名。具体字段查[证据矩阵](02_字段证据与交叉复核规范.md#3-逐字段复核矩阵)。

## 维护与验证

1. 新规则先写清版型、来源、确认日期、已知与未知；确有赛季或场次差异时在共同入口局部登记，不复制整季规则。
2. 只有当前需求涉及的规则才调整模板与验证器，核对实际调用方、枚举和导入适配；以一个真实样板验证，再做所需范围。
3. 规则变化时同步受影响的事件、导入和派生结果，运行对应语义回归；文档整理本身不触发重导或重新发布。

2026-10-29已合并运行配置，旧配置与模板的原始字节和路径对照见[历史配置快照](../data/extractions/shared/config_history/2026-10-29/README.md)。历史JSON／收据中的路径及哈希按原版本解释，不以新配置哈希替换历史来源哈希。已有数据库版型代码由共同模板的存储配置兼容，不批量改写历史对局。
